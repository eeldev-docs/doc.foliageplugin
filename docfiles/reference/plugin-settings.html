Reference

Plugin Settings

The settings are in Project Settings → Game → Foliage Plugin and are saved in DefaultGame.ini.

note

The screenshot is from an older version. Enable Replication no longer exists, replication is always on. Foliage Manager Class and Field System Actor are newer settings.

Foliage​

SettingDefaultDescription
Enable DebuggingOnShows on-screen debug messages and draws the blocking checks. See Logging and Debugging. Turn it off before you ship.
Foliage Data TableNoneThe Data Table with your resources. Its row structure must be FoliageData. See Data Table Settings.
Foliage Manager ClassFoliagePluginManagerThe manager class that is spawned automatically. See Custom Foliage Manager.
Hidden Foliage Move Distance10000How far down, in units on the Z axis, an instance is moved when it is hidden.

Settings​

SettingDefaultDescription
Foliage Respawn Rate60Seconds between respawn attempts. Minimum 10. See respawning.
Block Foliage Despawn Radius1000A Foliage Actor is not destroyed while an object of a blocked type is within this radius.
Block Foliage Respawn Radius1000An instance does not respawn while an object of a blocked type is within this radius.
Blocked Respawn Object TypesPawnObject types that block both despawning and respawning. Leave empty to never block.
Field System ActorFS_MasterFieldThe Field System Actor spawned to break Geometry Collections.
Field System Actor Life Span2Seconds a spawned Field System Actor stays before it is destroyed. Minimum 0.1.
Geometry Collection Actor ClassFoliagePluginGeometryCollectionActorThe actor spawned to show a destructible mesh. Set your own child class here.

Saving and Loading​

SettingDefaultDescription
Enable Persistent DataOffSaves hidden and removed instances between sessions.
Auto Saving Rate60Seconds between automatic saves. Minimum 5.
Save Game NameFoliageDataSave slot name.
Save Game Version1A save with a different version is ignored and overwritten.

See Saving and Loading.

Replication​

SettingDefaultDescription
Replicate Physics MovementOffReplicates the movement of depleted actors that simulate physics. Costs bandwidth, only turn it on if the positions matter for gameplay.
