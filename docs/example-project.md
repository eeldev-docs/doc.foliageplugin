# Example Project

The example project shows a complete setup: a Foliage Data Table with a tree and a rock, a Foliage Actor Blueprint, and a character that harvests foliage with a line trace.

- [Download Example Project](https://github.com/eeldev-ue4/FoliageExample/releases)

:::info
The example project does not include the plugin. Install the plugin first, see [Installing the Plugin](/docfiles/getting_started/installing).
:::
